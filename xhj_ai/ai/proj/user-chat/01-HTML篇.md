# HTML 语义化与文档结构

> 本文是 user-chat 全栈项目学习笔记系列第 1 篇，讲解 HTML 文档结构与语义化标签。

---

## 一、HTML 文档基础

### 1.1 DOCTYPE 声明

```html
<!DOCTYPE html>
```

- `!` 用于标记这是 HTML 的最新版本，即 **HTML5**
- 区别于 HTML4，HTML5 的声明更简洁
- 必须放在文档第一行

### 1.2 文档类型

| 类型 | MIME Type | 说明 |
|---|---|---|
| 纯文本 | `text/plain` | 不解析标签，原样显示 |
| HTML | `text/html` | 使用 HTTP 超文本传输协议，浏览器解析为文档 |

### 1.3 完整文档结构

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
    <!-- CSS 在头部引入：让 HTML 和 CSS 尽早结合，用户更早看到页面 -->
    <link href="bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <!-- 页面内容 -->
    <script src="./common.js"></script>
</body>
</html>
```

**为什么 CSS 放头部，JS 放尾部？**
- CSS 放 `<head>`：尽早下载解析，避免页面"裸奔"
- JS 放 `</body>` 前：等 DOM 加载完成后再执行，避免找不到元素

## 二、语义化标签

### 2.1 为什么需要语义化？

> div 用来做盒子，但不能一直用 div

**语义化的好处：**
1. **可读性**：代码结构清晰，便于维护
2. **SEO 友好**：搜索引擎更容易理解页面结构
3. **无障碍**：屏幕阅读器等辅助工具能正确解析
4. **大厂注重**：面试常考，体现前端基本功

### 2.2 常用语义化标签

```html
<header>    <!-- 页头：logo、导航、标题 -->
<main>      <!-- 主体内容：页面核心区域 -->
<aside>     <!-- 侧边栏：广告、相关链接 -->
<footer>    <!-- 页脚：版权、联系方式 -->
<nav>       <!-- 导航区 -->
<article>   <!-- 独立文章内容 -->
<section>   <!-- 内容区块 -->
<table>     <!-- 表格数据 -->
```

### 2.3 项目实例

```html
<body>
    <header>1111</header>
    <main class="container">
        <aside>侧边栏333</aside>
        <div class="row col-md-6 col-md-offset-3">
            <table class="table table-striped" id="user-table">
                <!-- 表格内容 -->
            </table>
        </div>
        <aside>侧边栏444</aside>
    </main>
    <footer>222</footer>
</body>
```

## 三、盒子模型

### 3.1 核心概念

> 先写盒子，再写内容

```
┌─────────────────────────────────┐
│  main.container (外层盒子)       │
│  ┌───────────────────────────┐  │
│  │  div.row (行盒子)         │  │
│  │  ┌─────────────────────┐  │  │
│  │  │  table (内容)       │  │  │
│  │  └─────────────────────┘  │  │
│  └───────────────────────────┘  │
└─────────────────────────────────┘
```

### 3.2 盒子模型组成

```
┌──────────────────────────────────┐
│           margin (外边距)         │
│  ┌────────────────────────────┐  │
│  │         border (边框)      │  │
│  │  ┌──────────────────────┐  │  │
│  │  │     padding (内边距) │  │  │
│  │  │  ┌────────────────┐  │  │  │
│  │  │  │   content      │  │  │  │
│  │  │  │   (内容区)     │  │  │  │
│  │  │  └────────────────┘  │  │  │
│  │  └──────────────────────┘  │  │
│  └────────────────────────────┘  │
└──────────────────────────────────┘
```

## 四、总结

| 知识点 | 核心要点 |
|---|---|
| DOCTYPE | HTML5 声明，文档第一行 |
| 语义化 | 用合适的标签，不要 div 一把梭 |
| CSS 位置 | 放 `<head>`，尽早加载 |
| JS 位置 | 放 `</body>` 前，等 DOM 完成 |
| 盒子模型 | 先写盒子结构，再填内容 |
