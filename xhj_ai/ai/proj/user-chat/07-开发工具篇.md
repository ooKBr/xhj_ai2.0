## 一、Emmet 补全语法

### 1.1 什么是 Emmet？

Emmet 是一个强大的代码快速生成工具，支持 HTML/CSS 快速补全，在 VS Code、Sublime 等编辑器中内置支持。

### 1.2 基础语法

| 语法 | 效果 |
|---|---|
| `div` | `<div></div>` |
| `div.container` | `<div class="container"></div>` |
| `div#header` | `<div id="header"></div>` |
| `div.container#main` | `<div class="container" id="main"></div>` |

### 1.3 嵌套语法

| 语法 | 含义 | 示例 |
|---|---|---|
| `>` | 子元素 | `ul>li` |
| `+` | 兄弟元素 | `div+p` |
| `^` | 上一级 | `div^p` |

```html
<!-- ul>li>a -->
<ul>
  <li><a href=""></a></li>
</ul>
```

### 1.4 重复与编号

```
ul>li.item$*3>a{Item $}
```

展开为：
```html
<ul>
  <li class="item1"><a href="">Item 1</a></li>
  <li class="item2"><a href="">Item 2</a></li>
  <li class="item3"><a href="">Item 3</a></li>
</ul>
```

### 1.5 属性与文本

| 语法 | 效果 |
|---|---|
| `a[href="#"]` | `<a href="#"></a>` |
| `p{Hello}` | `<p>Hello</p>` |
| `img[src="logo.png" alt="Logo"]` | 带多个属性 |

### 1.6 常用缩写

| 缩写 | 展开为 |
|---|---|
| `!` | HTML5 完整文档模板 |
| `link` | `<link rel="stylesheet" href="">` |
| `script` | `<script src=""></script>` |
| `meta:vp` | 视口 meta 标签 |

### 1.7 CSS 补全

| 输入 | 补全为 |
|---|---|
| `w100` | `width: 100px;` |
| `h100%` | `height: 100%;` |
| `m10` | `margin: 10px;` |
| `p10-20` | `padding: 10px 20px;` |
| `flex` | `display: flex;` |
| `pos:a` | `position: absolute;` |

### 1.8 实战示例

```
<!-- 生成 Bootstrap 布局 -->
.container>.row>.col-md-6*2

<!-- 生成表单 -->
form>label{Username}+input[type="text" name="username"]+label{Password}+input[type="password" name="password"]+button[type="submit"]{Login}
```

## 五、CDN 引入

### 5.1 什么是 CDN？

- **CDN** = Content Delivery Network（内容分发网络）
- 加速静态资源加载
- 不需要下载到本地

### 5.2 常用 CDN

```html
<!-- Bootstrap CSS -->
<link href="https://cdn.bootcdn.net/ajax/libs/twitter-bootstrap/3.0.3/css/bootstrap.min.css" rel="stylesheet">

<!-- jQuery -->
<script src="https://cdn.bootcdn.net/ajax/libs/jquery/3.6.0/jquery.min.js"></script>
```

### 5.3 CDN 的优点

- ✅ 加快加载速度
- ✅ 减少服务器带宽
- ✅ 不需要管理文件
