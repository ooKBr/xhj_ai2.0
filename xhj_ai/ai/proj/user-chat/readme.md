## AI 全栈开发
- 前后端模块化分离
  - 前端在 fe目录下
      opc 前端
  - 后端在 backend目录下
      opc 后端

### 前端
    三件套
      - html 负责结构 标签
      - css  负责样式 头部引入（更快下载 html和css尽早结合，更早让用户看到）
          css库  twitter 框架
      - js   负责行为
          通过script标签引入 common.js

## 模块化 module 拆分
- 设计思想
    代码，功能都放在一个文件，少数文件或目录  -> 不好维护，不好扩展，不好优化
    ∴ 每个文件夹需要有他的职责划分，每个文件只做一件事（一个文件一个类）
