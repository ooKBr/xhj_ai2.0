## 数组的创建

- ADT 的认识
    连续的存储空间 + 特定的操作
- push,pop,shift,unshift
  - 会修改原数组，破坏原来的数组，这些方法都不是纯函数
    - push 向数组末尾添加一个或多个元素，返回新长度
    - pop 从数组末尾删除一个元素，返回被删的元素
    - shift 从数组开头删除一个元素，返回被删的元素
    - unshift 向数组开头添加一个或多个元素，返回新长度
- 纯函数
- new Array(7)
  指定了长度的空数组
  返回结果是 [empty x 7] 而不是 undefined ，[empty x 7] 初始化为空
  empty 意思是数组的这个位置还没有被占据，不属于任何类型
  arr[0] 返回的是 undefined
- (new Array(7)).fill(1)
  创建一个长度确定，同时每一个元素也确定的值的数组

## 遍历的方法
- for 计数循环
    机器化，命令式，缺点是可读性不好
    优点是性能最好
- for of
    语义很好
- forEach
    入调用栈 执行上下文... 性能一般
    优点是功能强大
    缺点是不能中途break跳出循环
- map、filter、every、some
    基于forEach 实现的
    返回一个全新数组 纯函数
    filter 筛选 函数结果为true 的留下,返回一个留下元素组成的新数组
    every 每一项都满足结果，返回true，否则返回false
    some 有一项满足，返回true，否则返回false
    怎么选择？
