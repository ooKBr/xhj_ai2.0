# 一道经典算法题：用栈模拟队列

> 面试高频考点，一道题搞懂栈和队列的核心区别。

## 前言

面试中常遇到一道题：**用栈模拟队列**。这道题考察的不只是数据结构，更是对栈和队列本质的理解。

---

## 一、数据结构基础

### 1.1 线性 vs 非线性

```
数据结构
├── 线性
│   ├── 栈（FILO）
│   ├── 队列（FIFO）
│   └── 链表
└── 非线性
    └── 树
```

### 1.2 栈 vs 队列

| 特性 | 栈 Stack | 队列 Queue |
|------|---------|-----------|
| 原则 | **FILO** 先进后出 | **FIFO** 先进先出 |
| 比喻 | 弹夹装弹 | 排队买饭 |
| 入口 | 同一端进出 | 一端入，一端出 |

### 1.3 队列的四个核心操作

```javascript
push(x)    // 元素入队（尾部）
pop()      // 元素出队（首部）
peek()     // 查看队首元素
empty()    // 队列是否为空
```

---

## 二、核心思路：两个栈倒一倒

栈是先进后出，队列是先进先出。用一个栈做不到，但**两个栈配合**就可以了：

- **stackIn**：负责入队
- **stackOut**：负责出队

当 stackOut 空了，就把 stackIn 里的元素全部倒入 stackOut，顺序就反转了。

---

## 三、完整代码实现

```javascript
function MyQueue() {
    this.stackIn = [];   // 入队栈
    this.stackOut = [];  // 出队栈
}

// 入队：直接压入 stackIn
MyQueue.prototype.push = function(x) {
    this.stackIn.push(x);
}

// 出队：从 stackOut 弹出，若为空则把 stackIn 全部倒入
MyQueue.prototype.pop = function() {
    if (this.stackOut.length === 0) {
        while (this.stackIn.length > 0) {
            this.stackOut.push(this.stackIn.pop());
        }
    }
    return this.stackOut.pop();
}

// 查看队首
MyQueue.prototype.peek = function() {
    if (this.stackOut.length === 0) {
        while (this.stackIn.length > 0) {
            this.stackOut.push(this.stackIn.pop());
        }
    }
    return this.stackOut[this.stackOut.length - 1];
}

// 是否为空
MyQueue.prototype.empty = function() {
    return this.stackIn.length === 0 && this.stackOut.length === 0;
}
```

---

## 四、原理图解

```
push(1) push(2) push(3)

stackIn:  [1, 2, 3]   ← 顶部是 3
stackOut: []

pop() 时：
  stackOut 为空 → 把 stackIn 全部倒入 stackOut

  stackIn:  []
  stackOut: [3, 2, 1]   ← 顶部是 1

  弹出 1 ✅ 先进先出！
```

### 执行过程

| 操作 | stackIn | stackOut | 返回值 |
|------|---------|----------|--------|
| push(1) | [1] | [] | - |
| push(2) | [1,2] | [] | - |
| push(3) | [1,2,3] | [] | - |
| pop() | [] | [3,2] | 1 |
| peek() | [] | [3,2] | 2 |
| empty() | [] | [3,2] | false |

---

## 五、测试验证

```javascript
const queue = new MyQueue();
queue.push(1);
queue.push(2);
queue.push(3);

console.log(queue.pop());   // 1（先进先出 ✅）
console.log(queue.peek());  // 2
console.log(queue.empty()); // false
```

---

## 总结

| 要点 | 说明 |
|------|------|
| 栈的特性 | FILO，只能在一端操作 |
| 队列的特性 | FIFO，一端入一端出 |
| 核心思路 | 两个栈，一个入一个出，空了就倒 |
| 时间复杂度 | push O(1)，pop 均摊 O(1) |

一句话记住：**两个栈倒一倒，先进后出变先进先出。**
