# JS 有多少种数据类型？
八种数据类型
根据ECMA262 规范
primitive 原始数据类型有6种，null undefined numeric Boolean String Symbol,
其中numeric 再可分为number 和新增的bigint。还有一种对象object。
## 简单数据类型
也叫原始数据类型（Primitive Type）
- Number 数值
- Boolean 布尔值
- String 字符串
- null
    - 用于表示一个有意设置为空的对象引用（空的引用）
    - 表示某处应该有个值，不过目前没有（空的值）
    - 可以用于清空一个变量的值，释放内存，垃圾回收

- undefined
    表示一个未初始化 或不存在的变量值
    - 当申明一个变量但未赋值时（var 和 let，const 会报错，因为 const 是常量 申明时必须赋值）
    - 某个对象属性不存在
    - 函数没有返回值时
    - 访问不存在的数组索引
es6 以前， js 只有6种类型
### es6 新增数据类型
- symbol 唯一
- BigInt 大数
## 复杂数据类型
- object
也叫引用数据类型(内存分配)

## 内存分配去思考
- 冯诺依曼 现在计算设备
    运算器 控制器（cpu） 存储器(内存 外存) 输入 输出
- 代码 外存 硬盘
- 编译，代码从硬盘调入内存之中
- 执行上下文 变量环境，词法环境，执行代码，
- 推入**调用栈** 就在栈内存中
    快，空间小
    变量环境/词法环境  原始数据类型，再执行阶段赋值就直接写入值
    引用数据类型，也在栈内存中，只不过存的是对象的地址
    编译阶段给他的空间正好合适  函数执行上下文对象占用多少空间是算的出来的，当一个函数执行完，出栈，很快的算出新的栈顶元素，指针偏移量就可以切换上下文的执行
    快速、稳定、扩展
    堆内存
